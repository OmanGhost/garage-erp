# دليل مدير النظام

هذا الدليل لمدير الشركة (Company Admin) ولمدير المنصة (Super Admin). للتثبيت والنشر راجع [INSTALL.md](INSTALL.md) و[DEPLOYMENT.md](DEPLOYMENT.md).

---

## 1. مستويات الإدارة

| المستوى | من هو | ماذا يدير |
|---|---|---|
| **مدير المنصة (Super Admin)** | مزوّد الخدمة | الشركات (المستأجرون)، باقات الاشتراك، تفعيل/إيقاف الشركات، النسخ الاحتياطية الكاملة |
| **مدير الشركة (Company Admin)** | مالك الورشة أو مديرها | كل ما يخص شركته: الفروع، المستخدمون، الأدوار، الإعدادات، التكاملات |

البيانات معزولة تماماً بين الشركات: لا يمكن لمستخدم في شركة رؤية أي سجل من شركة أخرى، سواء من الواجهة أو من الـ API.

## 2. إدارة المنصة (SaaS) — لمدير المنصة

**إدارة المنصة**:

- **لوحة المنصة:** عدد الشركات، الاشتراكات النشطة والتجريبية والمتأخرة، الإيراد الشهري المتكرر (MRR).
- **مستأجر جديد:** إدخال بيانات الشركة والباقة وبريد مديرها. يُجهّز النظام تلقائياً: الفرع الرئيسي، المستودعات، دليل الحسابات الكامل، السنة المالية، الصناديق والبنوك، صندوق نقطة البيع، العميل النقدي، 14 قسماً للورشة، قائمة فحص، وقوالب الإشعارات.
- **الدخول إلى الشركة:** للدعم الفني، يمكن الدخول إلى بيانات أي شركة (يُسجّل في سجل التدقيق).
- **الباقات:** الأسعار الشهرية والسنوية، أيام التجربة، الحد الأقصى للمستخدمين والفروع والمستودعات والتخزين، والوحدات المتاحة. يمكن تجاوز وحدات الباقة لشركة معينة.
- **الاشتراك:** عند انتهاء الاشتراك يصبح النظام للشركة **للقراءة فقط** حتى التجديد.

الباقات الافتراضية: الأساسية (Starter)، الاحترافية (Professional)، المؤسسات (Enterprise).

### الموقع التعريفي وطلبات التجربة

- **الموقع العام:** الصفحة الرئيسية `/` بالعربية و`/en` بالإنجليزية: المميزات، الوحدات، الخطط والأسعار (تُقرأ مباشرة من الباقات، فأي تعديل في السعر يظهر فوراً)، الأسئلة الشائعة، ونموذج **طلب نسخة تجريبية** في `/trial`.
- **طلبات التجربة** (إدارة المنصة ← طلبات التجربة): تصل الطلبات مع إشعار داخل النظام، ورسالة بريد إن أُدخل "بريد التنبيه". غيّر الحالة (جديد / تم التواصل / مرفوض) وأضف ملاحظاتك. زر **إنشاء شركة تجريبية** يجهّز الشركة كاملة بالباقة المختارة ويُنشئ حساب مدير ببريد العميل، وتظهر كلمة المرور المؤقتة مرة واحدة لتُرسلها له بطريقة آمنة.
- **الحماية من الرسائل المزعجة:** حقل خفي للروبوتات، رفض الإرسال الفوري، وحد 5 طلبات في الساعة لكل عنوان IP. الطلبات المكررة بنفس البريد لا تُكرر.
- **نصوص الموقع** في الملفين `lang/ar/site.php` و`lang/en/site.php` (العناوين، المميزات، الأسئلة الشائعة…). راجع الوعود التسويقية فيها (مثل "خلال يوم عمل") بما يناسب خدمتك.

### الموقع وتحسين محركات البحث (SEO)

إدارة المنصة ← **الموقع وتحسين محركات البحث**:

| الإعداد | الاستخدام |
|---|---|
| السماح بالأرشفة | أوقفه على خوادم الاختبار؛ يصبح الموقع `noindex` ويمنع robots.txt كل شيء |
| عنوان الصفحة والوصف (عربي/إنجليزي) | يظهران في نتائج جوجل. العداد يوضح الطول المستحسن (60 / 160 حرفاً) مع معاينة مباشرة |
| الكلمات المفتاحية | اختيارية |
| رموز تحقق Google Search Console وBing | تُضاف تلقائياً كوسوم meta |
| Google Analytics 4 | اختياري، يُحمّل فقط عند إدخال المعرّف |
| صورة المشاركة 1200×630 | تظهر عند مشاركة الرابط في واتساب وX ولينكدإن |
| بيانات التواصل والشبكات الاجتماعية | تظهر في التذييل وفي البيانات المنظمة |

ما يعمل تلقائياً: وسم canonical، روابط hreflang بين العربية والإنجليزية، Open Graph وTwitter Cards، بيانات منظمة schema.org (المنظمة، الموقع، التطبيق مع الأسعار بالريال، الأسئلة الشائعة، مسار التنقل)، `sitemap.xml`، و`robots.txt` الذي يمنع صفحات النظام. كل صفحات النظام الداخلية (لوحة التحكم، البوابة، الدخول، الـ API) تُرسل `X-Robots-Tag: noindex`.

**بعد النشر:** اضبط `APP_URL` على النطاق الحقيقي (https)، ثم أضف الموقع في Google Search Console وأرسل `https://نطاقك/sitemap.xml`.

## 3. إعدادات الشركة

**الإدارة ← الإعدادات**

| القسم | الإعدادات |
|---|---|
| ملف الشركة | الاسم بالعربية والإنجليزية، السجل التجاري، الرقم الضريبي، العنوان، الشعار، لون العلامة |
| العملة والضرائب | الريال العماني (3 خانات عشرية)، نسبة ضريبة القيمة المضافة الافتراضية 5% |
| سير عمل الورشة | اشتراط عرض سعر معتمد قبل العمل، اشتراط فحص الجودة قبل التسليم، اشتراط السداد قبل التسليم (للعملاء النقديين)، تكلفة العمالة الافتراضية بالساعة، السعة اليومية |
| المخزون | طريقة التقييم: **المتوسط المرجح** أو **FIFO**، السماح بالمخزون السالب (غير مستحسن)، تنبيهات انخفاض المخزون |
| المبيعات | السماح بالبيع الآجل فوق حد الائتمان، صلاحية عرض السعر (أيام)، تذييل الفاتورة بالعربية والإنجليزية والشروط |
| المشتريات | حد اعتماد أوامر الشراء (الأوامر الأعلى تحتاج صلاحية "اعتماد بلا حد") |
| الموارد البشرية | معامل العمل الإضافي، دقائق العمل اليومية |
| المتجر الإلكتروني | التفعيل، رسوم التوصيل، الحد الأدنى للطلب |

> غيّر طريقة تقييم المخزون قبل بدء الحركات الفعلية فقط.

## 4. الفروع والمستودعات

- **الفروع:** الإدارة ← الفروع. لكل فرع مركز تكلفة؛ تظهر ربحية كل فرع في التقارير.
- **المستودعات والمواقع:** قطع الغيار ← المستودعات / الرفوف والمواقع.
- **صلاحيات الوصول:** من صفحة المستخدم ← **الوصول**: الفرع الافتراضي، الفروع الإضافية، المستودعات، والأقسام (للفنيين). صلاحية **جميع الفروع** تعطي رؤية كل الفروع.
- **ساعات العمل والعطلات الرسمية:** تتحكم في المواعيد المتاحة.

## 5. المستخدمون والأدوار

**الإدارة ← المستخدمون**: إنشاء مستخدم، تعيين دوره وفرعه، تعطيله (لا يُحذف من له حركات). لا يمكن للمستخدم تعطيل أو حذف حسابه.

**الإدارة ← الأدوار والصلاحيات**: الأدوار الجاهزة:

| الدور | الوصف المختصر |
|---|---|
| مدير الشركة | كل الصلاحيات |
| المدير العام | عرض واعتماد وتقارير كل الفروع |
| مدير الفرع | تشغيل الفرع كاملاً: العملاء، الورشة، الفواتير، المدفوعات |
| مدير الورشة | الأقسام، الخدمات، الفحص، بطاقات العمل، الجودة |
| موظف الاستقبال | العملاء، المركبات، الاستقبال، المواعيد، عروض الأسعار |
| الفني | بطاقات العمل المسندة إليه والفحص |
| مراقب الجودة | فحوصات الجودة |
| أمين المخزن | القطع، المخزون، التحويلات، الجرد، الاستلام، التفكيك |
| مسؤول المشتريات | الموردون، طلبات الشراء، طلبات العروض، أوامر الشراء |
| موظف المبيعات | نقطة البيع، فواتير وعروض أسعار القطع |
| أمين الصندوق | نقطة البيع، ترحيل الفواتير، سندات القبض |
| المحاسب | الحسابات، القيود، البنوك، الأصول، الموازنات، الإقفال |
| مدير الموارد البشرية | الموظفون، الحضور، الإجازات، الرواتب |
| المدقق | عرض وتصدير فقط + سجل التدقيق |
| العميل | بوابة العملاء فقط |

يمكن إنشاء **دور مخصص** واختيار صلاحياته (عرض، إنشاء، تعديل، حذف، طباعة، تصدير، اعتماد لكل مورد)، إضافة إلى صلاحيات خاصة مثل:

- `job_cards.override_workflow`: تجاوز سير عمل بطاقة العمل وفحص الجودة. **لا يتجاوز** شروط الفوترة والسداد قبل التسليم ولا شروط الإلغاء.
- `pos.discount_override`, `pos.below_min_price`: الخصم فوق المسموح أو البيع تحت الحد الأدنى.
- `invoices.credit_override`: البيع الآجل فوق حد الائتمان.
- `stock.allow_negative`, `purchase_orders.approve_unlimited`, `journal_entries.reverse`, `fiscal_years.close_period`.

الأدوار الجاهزة للنظام لا تُعدّل مباشرة؛ أنشئ دوراً مخصصاً إن احتجت صلاحيات مختلفة. لا يمنح دور "مدير الشركة" إلا مدير شركة.

## 6. ترقيم المستندات

**الإدارة ← ترقيم المستندات**: البادئة لكل نوع مستند (فاتورة، عرض سعر، بطاقة عمل…)، الرقم التالي، وإعادة الترقيم سنوياً. الصيغة الافتراضية `PREFIX-YYYY-000001`. الترقيم آمن مع الاستخدام المتزامن ولا يتكرر.

## 7. دليل الحسابات والفترات المالية

- **دليل الحسابات** جاهز ومرتبط بالقيود الآلية عبر "مفتاح النظام" (الصندوق، العملاء، الموردون، المخزون، تحت التشغيل، ضريبة المدخلات والمخرجات…). يمكن إضافة حسابات فرعية؛ لا تحذف حسابات النظام.
- **الأرصدة الافتتاحية:** المحاسبة ← الأرصدة الافتتاحية. أي فرق يُرحّل إلى حقوق ملكية الأرصدة الافتتاحية. كميات المخزون الافتتاحية تُدخل بتسوية مخزون بسبب "افتتاحي".
- **إقفال الفترات** يمنع أي تعديل على الأشهر المغلقة. إقفال السنة نهائي.
- **الإهلاك** يعمل تلقائياً أول كل شهر للشهر السابق، ويمكن تشغيله يدوياً.

## 8. الإشعارات والتكاملات

**الإدارة ← قوالب الإشعارات**: نصوص الرسائل بالعربية والإنجليزية لكل حدث (استلام المركبة، عرض سعر، جاهزية المركبة، تذكير الموعد، تذكير الصيانة…). المتغيرات المتاحة: `{{customer_name}}`، `{{number}}`، `{{total}}`، `{{link}}`، `{{plate}}`، `{{status}}`، `{{date}}`، `{{time}}`، `{{company_name}}`. تعديل قالب النظام ينشئ نسخة خاصة بشركتك.

**الإدارة ← التكاملات** (كلها اختيارية ومعطلة افتراضياً، وتُحفظ بياناتها مشفرة):

| التكامل | الاستخدام |
|---|---|
| بوابة الرسائل SMS (HTTP) | أي مزود رسائل عماني يدعم HTTP |
| واتساب للأعمال (Cloud API) | إرسال الإشعارات عبر واتساب |
| بوابة الدفع | للمتجر الإلكتروني وبوابة العملاء (يتوفر وضع تجريبي) |
| فك رقم الشاصي (NHTSA vPIC) | مجاني |
| أجهزة الحضور | رمز جهاز لإرسال البصمات إلى `/api/v1/attendance/punch` |

البريد الإلكتروني (SMTP) يُضبط في ملف `.env` على الخادم.

**Webhooks:** إرسال الأحداث (`invoice.posted`، `payment.received`، `job_card.status_changed`) لأنظمة خارجية مع توقيع HMAC.

**مفاتيح API:** الملف الشخصي ← مفاتيح API. راجع [API.md](API.md).

## 9. الأمان

- **التحقق الثنائي (2FA):** فعّله لكل المديرين والمحاسبين (الملف الشخصي ← الأمان).
- **سجل الدخول:** الإدارة ← سجل الدخول (المستخدم، الوقت، IP، المتصفح، نجاح/فشل).
- **سجل التدقيق:** كل إنشاء وتعديل وحذف وترحيل وتغيير صلاحيات مع القيم القديمة والجديدة والمستخدم والوقت.
- **الجلسات:** يمكن لكل مستخدم تسجيل الخروج من جلساته الأخرى. تغيير كلمة المرور يُنهي الجلسات الأخرى تلقائياً.
- **منع التكرار:** النقر المزدوج على أي نموذج لا يُنشئ مستنداً مكرراً.
- **حماية السجلات المالية:** المستندات المرحّلة لا تُعدّل ولا تُحذف؛ التصحيح بالعكس أو الإشعار الدائن.
- **SIEM:** يمكن إرسال أحداث الأمان إلى نظام SIEM عبر Syslog (إعدادات `SIEM_*` في `.env`).
- محاولات الدخول محدودة (5 في الدقيقة) لمنع التخمين.

## 10. النسخ الاحتياطي

نسخة كاملة تلقائية يومياً الساعة 2:00 صباحاً (قاعدة البيانات + الملفات المرفوعة). صفحة **النسخ الاحتياطية** متاحة لمدير المنصة، أو لمدير الشركة إذا كان النظام مثبتاً لشركة واحدة فقط (تثبيت محلي)، لأن النسخة تحتوي بيانات كل الشركات. التفاصيل والاستعادة في [BACKUP_RESTORE.md](BACKUP_RESTORE.md).

## 11. المهام اليومية التلقائية

يعمل النظام يومياً الساعة 7:00 صباحاً (بتوقيت مسقط) على:

- إرسال تذكيرات الصيانة الدورية وتذكيرات المواعيد
- تعليم المواعيد الفائتة "لم يحضر"
- إنهاء عروض الأسعار والضمانات منتهية الصلاحية
- تنبيه المديرين بالقطع التي تحتاج إعادة طلب، ووثائق الموظفين التي تنتهي خلال 30 يوماً، والمعدات المستحقة للصيانة أو المعايرة
- تحديث حالة الاشتراك

يتطلب ذلك تشغيل المجدول (cron) كما في دليل النشر.

## 12. حل المشكلات الشائعة

| المشكلة | الحل |
|---|---|
| لوحة الورشة لا تتحدث تلقائياً | تأكد من تشغيل Reverb و`BROADCAST_CONNECTION=reverb`؛ وإلا حدّث الصفحة يدوياً |
| الرسائل لا تُرسل | تأكد من تشغيل عامل الطوابير (`queue:work`) ومن إعدادات التكامل |
| "المخزون غير كافٍ" | راجع الكمية المحجوزة لبطاقات العمل في أرصدة المخزون |
| "الفترة المحاسبية مغلقة" | أعد فتح الفترة (صلاحية المحاسب) أو استخدم تاريخاً في فترة مفتوحة |
| "تجاوز حد الائتمان" | ارفع حد ائتمان العميل أو امنح المستخدم صلاحية تجاوز الحد |
| النظام للقراءة فقط | انتهى الاشتراك؛ تواصل مع مدير المنصة للتجديد |
