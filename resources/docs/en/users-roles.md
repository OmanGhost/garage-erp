# Users & roles

Every user sees and does only what their role allows.

## Built-in roles
| Role | Main rights |
|---|---|
| Company Admin | Everything |
| General Manager | View and approve all departments |
| Branch Manager | Branch operations, sales and workshop |
| Receptionist | Reception, job cards, appointments |
| Technician | Own tasks and parts for job cards |
| Storekeeper | Parts, stock and receiving |
| Cashier | POS and collection |
| Accountant | Accounts, journals and financial reports |
| Auditor | Read-only with the audit log |

## Adding a user
**Users → New**: name, email, an initial password, role and branch; the user then changes the password from their profile.

## Changing permissions
In **Roles** edit any role or create a new one. Rights are per module: view, create, update, delete, approve, print, export.

## Security
- Turn on **two-factor authentication** for users with broad rights.
- Review the **login history** and **audit log** regularly.
