# المخزون وقطع الغيار

إدارة القطع والمستودعات والتكلفة والجرد.

## القطع
- رقم القطعة والباركود والعلامة والتصنيف وسعر البيع (تجزئة، جملة، ورشة).
- **الأرقام البديلة:** اربط الرقم الأصلي بالبدائل التجارية والمستعملة والمتوافقة.
- حد إعادة الطلب والكمية الاقتصادية.

## التكلفة
متوسط مرجح أو FIFO من الإعدادات. كل استلام وصرف وتحويل يُرحَّل محاسبياً تلقائياً.

## الحركات
- **التحويل** بين المستودعات بإرسال واستلام.
- **التسوية** لزيادة أو نقص بسبب تلف أو فقد — موثقة بالسبب والمستخدم.
- **الجرد** الدوري أو المستمر: اطبع ورقة العد، أدخل الكميات، ورحّل الفروقات.

## التحليلات
تحليل ABC، والمخزون الراكد، وعمر المخزون، وتوقع الطلب، وإعادة الطلب التلقائي.
