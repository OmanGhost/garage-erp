# المستخدمون والصلاحيات

كل مستخدم يرى ويفعل فقط ما يسمح به دوره.

## الأدوار الجاهزة
| الدور | أهم الصلاحيات |
|---|---|
| مدير الشركة | كل شيء |
| المدير العام | عرض واعتماد كل الأقسام |
| مدير الفرع | تشغيل الفرع والمبيعات والورشة |
| موظف الاستقبال | الاستقبال وأوامر العمل والمواعيد |
| الفني | مهامه وصرف القطع لأوامر العمل |
| أمين المخزن | القطع والمخزون والاستلام |
| الكاشير | نقطة البيع والتحصيل |
| المحاسب | الحسابات والقيود والتقارير المالية |
| المدقق | عرض فقط مع سجل التدقيق |

## إضافة مستخدم
من **المستخدمون ← جديد**: الاسم والبريد وكلمة مرور أولية والدور والفرع، ثم يغيّر المستخدم كلمة المرور من ملفه الشخصي.

## تعديل الصلاحيات
من **الأدوار** يمكنك تعديل صلاحيات أي دور أو إنشاء دور جديد. الصلاحيات مقسمة لكل وحدة: عرض، إنشاء، تعديل، حذف، اعتماد، طباعة، تصدير.

## الأمان
- فعّل **المصادقة الثنائية** للمستخدمين ذوي الصلاحيات الواسعة.
- راجع **سجل الدخول** و**سجل التدقيق** دورياً.
